# Code of conduct

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep technical disagreement focused on the
work. Harassment, discrimination, threats, doxxing, credential sharing, and
publishing another person's prompts or private data are not acceptable.

Maintainers may edit or remove comments, close issues, or block accounts that
make the project unsafe or unproductive. To report a conduct issue privately,
contact the maintainer through GitHub at
<https://github.com/ahmed-dev25>.

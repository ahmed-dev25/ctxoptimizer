# Security policy

## Supported versions

Only the latest release on `main` is supported with security fixes.

## Reporting a vulnerability

Do **not** open a public issue for a vulnerability, leaked credential, or
privacy-sensitive report.

Use GitHub's private vulnerability reporting:
<https://github.com/ahmed-dev25/ctxoptimizer/security/advisories/new>

Please include:

- affected version and platform;
- a minimal reproduction;
- impact and any suggested fix;
- whether the issue involves a real provider credential (do not include the
  credential itself).

You can expect an initial acknowledgement within a few days. Please give the
maintainer reasonable time to ship a fix before public disclosure.

ctxproxy — The Agent-Run Cost Optimizer

A transparent local HTTP proxy between AI coding agents and LLM providers. Every request is measured, cleaned, cached, attributed, and explained — by pure deterministic code — while the agent, the provider, and the user experience nothing except a smaller bill and a dashboard that finally tells them where their money went.

01The Entire Flow — One Agent Turn, Step by Step

What happens every time your coding agent sends a request through the proxy.

Setup (once, per machine)

1. uv tool install ctxproxy — one command.

2. Point clients at the proxy: ANTHROPIC_BASE_URL=http://127.0.0.1:8787  ·  OPENAI_BASE_URL=http://127.0.0.1:8787/v1

3. First run = shadow mode: watches & reports, forwards everything untouched. Trust is earned before any change is permitted. Switch to active when convinced.

1
Receive & Route server.py · routing.py

Request arrives on 127.0.0.1:8787. Router identifies provider (Anthropic / OpenAI / Gemini / Ollama), endpoint kind, session id (from header or derived from content), and project. Anything unknown → raw passthrough, untouched, telemetered lightly.

zero code changes for clientsloopback-only by default
2
Decode & Analyze analysis/*

JSON parsed once (orjson). Payload becomes segments — tool defs, system prompt, message blocks — each hashed & token-estimated.

Drift detector: "prefix changed here → that's why your cache missed" causes: tools · system · params · history · TTL · config · model switch
3
Optimize — the Transform Pipeline transforms/*

Deterministic, cache-safe payload reductions on tool-result text only (user & assistant text untouched by default). Fixed order, time-budgeted, guarded:

ansi_strip→ progress_collapse→ line_dedupe→ whitespace_trim→ smart_truncate→ duplicate_backref→ cache_serve→ stale_result_elision (opt-in)→ anthropic_cache / openai_hints

Shadow mode runs everything, then discards the result and keeps only the report ("what would have been saved?").

4
Attribute the Waste analysis/waste.py — the unique layer

Detectors compare hashes across turns & sessions and record Waste Findings: "file re-read unchanged 3× (≈$0.41)", "4 reads could be one batch", "session burned 40 min with no result", "your system-prompt timestamp busts the cache every turn." Pure counters, hashes, thresholds — findings never mutate traffic (INV-16).

8 determinstic detectors: W1–W8see taxonomy ↓
5
Forward & Measure Ground Truth proxy.py

Request streams to the provider; response streams straight back to the client — byte-for-byte, never buffered, zero perceived latency. A side-channel tee parses the provider's own usage numbers: real tokens, real cache hits. Provider errors (429 etc.) pass through verbatim.

6
The Honest Math analysis/baseline.py · pricing.py

Actual cost from provider usage. A simulator computes what the untouched request would have cost. Savings are always labeled sim./est. and continuously calibrated against reality (INV-13, INV-18).

7
Store, Visualize, Coach telemetry/* · dashboard/*

Everything lands in local SQLite. Dashboard at localhost:8787/_ctxproxy: live $ burn, actual vs simulated cost, cache health, Waste Opportunities ranked by $, and one-click Recommendations ("prune 3 unused MCP tool schemas — projected $X/mo"). CLI mirror: stats · waste · recommend.

8
The Retrieval Loop — nothing is lost mcp.py

Any transform that omitted content leaves a pointer. The agent can call the local MCP tool ctxproxy_expand(ref) and get the original bytes back on demand. Deletions become lazy loading; the agent is never left without a path to the truth.

9
Self-Tuning Guard §12.14

Continuous policy: too many fallbacks · any "our-fault" drift · broken expand refs · a transform earning nothing → that transform auto-drops to shadow for the session, with alarm + evidence. The product tunes itself per codebase instead of fighting the user.

04Where LLMs Are (and Are Not) Used

⚡ Inside the proxy: zero LLM calls. Zero tokens. Zero added cost of intelligence.

Every decision — cleaning, caching, attribution, recommendations, guard rules — is a hash, regex, counter, or threshold check. Determinism, latency, and cost guarantees are absolute (spec rule D15). Anything "speculative" (cheap-model routing with LLM verification, fix-up interception) is deliberately deferred to a gated future phase that must first pass its own break-even rule (verification spend ≤ 10% of what it protects, circuit-breakable, deterministic-first ladder).

hashes & regexes· counters & thresholds· provider-reported usage (billed by provider) ⟶ the only LLM in the picture is the one the user was already paying

Why this matters

The proxy promises "cheaper" without charging tokens to be clever. A competitor that calls an LLM to summarize competes against itself: its savings partially pay its own inference bill. ctxproxy's interventions cost microseconds of CPU.

The verification ladder (future-proofing)

Deterministic checks (hash/mtime) → free repo signals (tests pass) → parsed invariants → only then a tiny sampled model judge — and only if the EV math clears. LLM is the method of last resort, never the first.

05Safety & Self-Tuning — Why Nobody Gets Hurt

Hard invariants (INV-1…INV-18) make failure boring: the worst outcome is always "unchanged quality, no savings."

Fail-open (INV-1)

Any proxy error → original request forwarded untouched. Proxy bugs can never surface as client errors.

Shadow-first (D3)

Default mode mutates nothing. Users see potential savings in shadow, actual savings in active — never invented numbers (INV-13).

Retry-with-original (§9.7)

Provider rejects a mutated request (400/422)? The original is resent automatically. Downside of a transform bug ≈ zero.

No-regress + budget (INV-10)

A transform that doesn't save ≥ N tokens is reverted. Total CPU time per request is capped (250 ms budget).

Byte-truth only (T0)

cache_serve/backrefs emit stubs only when the content is hash-provably identical. The proxy never lies — only cheaper truths.

Auto-quarantine (§12.14)

Fallback storms, our-fault drift, broken expand refs, or no savings → that transform drops to shadow for the session, with evidence. Reversible, session-scoped.
